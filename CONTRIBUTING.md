# Contributing

## Local Preview

```shell
npx serve .
```

## Pull Requests

- Keep changes focused by page, asset group, or site behavior.
- Include screenshots for visual changes.
- Preserve the in-world municipal/archive voice.
- Check internal links when moving or renaming pages.
- Keep image filenames descriptive and stable.

## Content Notes

Do not smooth away the period texture. The site should feel intentional, restored, and slightly bureaucratic rather than modernized.
