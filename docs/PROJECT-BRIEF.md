# Project Brief

## Purpose

Lost Hills Web is an in-world static website for a fictional town. It works because it behaves like a real municipal web portal: dry, practical, oddly specific, and full of local texture.

## Audience

- Visitors exploring the Lost Hills fiction
- People inspecting the project as a static web artifact
- Future maintainers adding pages, clues, or civic ephemera

## Product Principles

- The site should feel found, not explained.
- Static pages are a feature, not a limitation.
- Small details carry the worldbuilding.
- Modern polish should stay invisible: fast loading, stable links, clean asset organization.
- The municipal voice should stay straight-faced.

## Content Families

- City government and public works pages
- Local business pages and ads
- News/community pages
- Conference and civic event material
- Restricted/archive records
- Image assets that sell the place as real

## High-Risk Areas

- Broken links can puncture the artifact.
- Too-modern UI language can weaken the fiction.
- Renaming assets can silently break pages.
- Restricted pages should remain intentional and discoverable only where intended.
